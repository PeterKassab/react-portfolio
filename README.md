# React Portfolio

Work in progress. Built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

The focus is on writing front-end code the way it would be written in a professional environment: structured components, typed data, and clear separation of concerns.

This is a no AI generated code project. Every line was written by hand, the goal is an honest and realistic demonstration of how I work.

## Running locally

```bash
npm install
npm run dev
```

## Stack

- Next.js 16
- App Router
- React 19
- TypeScript
- Tailwind CSS v4

## Structure

```
src/
  app/        # routes
  components/ # UI components
  data/       # mock data
```
